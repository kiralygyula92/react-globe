## Before a public release

1. Publish under an installable npm name — `react-globe` belongs to another package (G-01); this also
   unlocks the demo sandbox action (E-12).
2. Make the repository public and choose a host that honours `_redirects`; build with `DOCS_SITE_URL`
   set, then re-run `pnpm docs:qa` against production (G-02, G-18).
3. Decide which library behaviours in G-19 to fix; update each page's Limitations when one is fixed.

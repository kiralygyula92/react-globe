React Globe is one component with many capabilities. Each card below opens a page that starts with a
live demo, shows the variations, how to customize it, its known limitations and the API it uses.

The features cover drawing and interacting with the globe on the client. Map tiles, geocoding, routing,
server-side rendering and data storage are deliberately out of scope: supply coordinates and data from
your own application.

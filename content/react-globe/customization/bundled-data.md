The package ships every file it needs in `dist/assets/`, about 7 MB in total. All of it is in the public
domain, so using the defaults in any product carries no attribution or licence obligation.

## Datasets

| File | Contents | Source |
|---|---|---|
| `countries-50m.geojson` | Country polygons with ISO codes, label points and names in six languages | [Natural Earth](https://www.naturalearthdata.com/) 1:50m admin-0 countries; names from Natural Earth and [Wikidata](https://www.wikidata.org/) |
| `coastline-50m.geojson` | Coastlines | Natural Earth 1:50m coastline |
| `borders-50m.geojson` | Land boundaries between countries | Natural Earth 1:50m admin-0 boundary lines |
| `capitals-50m.json` | National capitals with names in six languages | Natural Earth 1:50m populated places; names from Natural Earth and Wikidata |

## Textures

| File | Used by | Source |
|---|---|---|
| `earth-day-8192.jpg` | `realistic` style | NASA Blue Marble: Next Generation, July 2004 |
| `earth-day-2048.jpg` | `realistic` preview; land cover for the shaded styles | Same, downscaled |
| `earth-clouds-2048.jpg` | `realistic` cloud layer | NASA Earth Observatory cloud composite |
| `earth-topology.png` | Relief for `standard` and `modern` | NASA Visible Earth GEBCO elevation |
| `earth-normal-2048.jpg` | `realistic` surface detail | Computed from `earth-topology.png` |
| `earth-specular-2048.jpg` | `realistic` water reflections | Rasterised from Natural Earth land and lakes |

## Rebuilding

The files are generated by `scripts/globe-assets.mjs` in the repository, which downloads every source,
simplifies coordinates to about 110 m of precision, derives the normal and specular maps, and adds the
translated names:

```bash
pnpm assets            # everything
pnpm assets datasets   # only the GeoJSON and capitals
pnpm assets textures   # only the images
```

## Replacing them

See [Custom assets](/react-globe/custom-assets/) for which files the `assets` prop can replace.

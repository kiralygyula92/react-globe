Version 1.0.0 was the first release; 1.x is the only major version so far.

## Numbering

React Globe follows [Semantic Versioning](https://semver.org/):

- **Patch** releases fix bugs without changing the API.
- **Minor** releases add features without breaking existing code.
- **Major** releases may break the API; each comes with a migration guide.

Every release is recorded in the [Changelog](/react-globe/discover-more/changelog/).

## Support policy

The latest major version receives fixes. When a new major version is released, the documentation for
the previous one stays online at a stable address, and its migration guide is kept permanently.

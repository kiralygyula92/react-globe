# react-globe

An interactive, detailed 3D Earth for React, drawn with plain three.js.

- **One component, everything as props.** `<Globe />` with no props renders a physical-map Earth
  with shorelines and country borders, drag to orbit, right-drag to tilt, wheel or pinch to zoom.
- **Four render styles**: `standard` (cel-shaded physical map), `realistic` (satellite imagery,
  clouds, atmosphere), `cartoon` (printed atlas) and `modern` (neon).
- **Pins, clustering, popups and great-circle connections**, with the default pin marker drawn as
  one instanced WebGL mesh.
- **Every visual element replaceable** with your own React component, and themeable through CSS
  custom properties.
- **Localized** in English, Romanian, German, Spanish, French and Hungarian, including bundled
  country and capital names.
- **Self-hosted, public-domain assets.** Nothing is fetched from a third-party host at runtime.
- **Renders on demand.** A globe nobody is interacting with skips drawing.

## Requirements

| | Declared range | Tested with |
|---|---|---|
| `react`, `react-dom` | `>= 19` | 19.3 |
| `three` | `>= 0.170` | 0.186 |
| Bundler | any that copies `new URL('./asset', import.meta.url)` files | Vite 8 |
| Browser | WebGL 2 | Chromium (Playwright) |

Nothing else is required at runtime.

## Install

```bash
npm install react-globe three
npm install -D @types/three
```

Import the stylesheet once, at your app entry:

```tsx
import 'react-globe/globe.css';
```

The stylesheet is compiled Tailwind with no preflight (your base styles are untouched) and every
utility prefixed `rg:`, so it cannot collide with your own Tailwind.

## Use

The component fills its container, **so the container must have a size**:

```tsx
import { Globe } from 'react-globe';
import 'react-globe/globe.css';

export function Example() {
  return (
    <div style={{ height: 500 }}>
      <Globe />
    </div>
  );
}
```

### Vite dev server

The package imports `three/examples/jsm/lines/*`. Pre-declare them so the dev server does not
re-optimise mid-session (which answers in-flight requests with a 504):

```ts
// vite.config.ts
optimizeDeps: {
  include: [
    'three',
    'three/examples/jsm/lines/Line2.js',
    'three/examples/jsm/lines/LineGeometry.js',
    'three/examples/jsm/lines/LineMaterial.js',
    'three/examples/jsm/lines/LineSegments2.js',
    'three/examples/jsm/lines/LineSegmentsGeometry.js',
  ],
}
```

### `Globe` or `GlobeLazy`

`GlobeLazy` takes the same props behind `React.lazy` + `Suspense`, with a wordless placeholder.
The package entry also exports `Globe` statically, so importing anything from the package pulls
`Globe` into that chunk. To keep three.js out of a chunk entirely, make your own import dynamic:

```tsx
const Stage = lazy(() => import('./Stage').then((m) => ({ default: m.Stage })));
```

`zoom` is a **distance from the globe's centre**, so smaller is closer. The field of view is 50°,
which puts the whole planet in frame from about 2.4 radii outward. **Home** — the pose the globe opens
on and `reset()` returns to — is `defaultCamera` over `defaultCenter` over
`{ lat: 20, lng: 0, zoom: 2.6, tilt: 0 }`.

**The default pin marker is WebGL; an override is DOM.** With no `pinComponent`, every pin is one
instance in an instanced mesh, one draw call however many pins. Passing `pinComponent` switches to one
DOM node per visible, unclustered pin: more flexible, heavier.

The default popup reads `Pin.data` by convention: title from `title`, `name` or `label` (else the pin
id); subtitle from `subtitle`, `description` or `caption`.

## `GlobeHandle`

Attach a `ref`, or take the handle from `onReady`. Its identity is stable for the life of the mount.
Both projection methods work in the container's coordinate space, origin top-left.

<!-- docs:reference:handle:start — generated by `pnpm docs:reference` from src/types.ts; do not edit -->
| Method | Signature | Description |
|---|---|---|
| `setCamera` | `(pose: CameraPose, opts?: { animate?: boolean; durationMs?: number }) => void` | Moves the camera to a pose; members left out keep their current value. Animated unless `animate: false` or reduced motion is on. |
| `reset` | `(opts?: { animate?: boolean; durationMs?: number }) => void` | Returns the camera to the pose the globe opened on: centre, zoom and tilt. |
| `flyTo` | `(target: LatLng, opts?: { zoom?: number; durationMs?: number }) => void` | Flies the camera to centre a coordinate, optionally at a new zoom. |
| `zoomIn` | `(step?: number) => void` | Moves the camera closer by a fraction of the current distance (default 0.2). |
| `zoomOut` | `(step?: number) => void` | Moves the camera away by a fraction of the current distance (default 0.2). |
| `startAutoRotate` | `(speed?: number) => void` | Spins the globe until stopped. Speed 1 is about 7 degrees per second. Paused under reduced motion. |
| `stopAutoRotate` | `() => void` | Stops auto-rotation. |
| `getCamera` | `() => Required<CameraPose>` | The current camera pose. |
| `latLngToScreen` | `(point: LatLng) => ScreenPoint \| null` | Projects a coordinate into the container; null when the globe hides it. |

## Render overrides

```tsx
// pinComponent — the wrapper is already positioned and rotated to the surface normal.
function SquarePin({ pin, hovered, scale }: PinRenderProps<MyData>) {
  return (
    <span
      style={{ transform: `translate(-50%, -50%) scale(${scale})` }}
      className={hovered ? 'block h-3 w-3 bg-white' : 'block h-3 w-3 bg-purple-500'}
      title={pin.data?.title}
    />
  );
}

// pinPopupComponent — arbitrary React, including your own app components.
function MyPopup({ pin, placement, close }: PinPopupRenderProps<MyData>) {
  return <article onClick={close}>{pin.data?.title} ({placement})</article>;
}

// clusterComponent — `count` is the number of pins merged into this marker.
function MyCluster({ count, onClick, messages }: ClusterRenderProps<MyData>) {
  return <button type="button" aria-label={messages.cluster(count)} onClick={onClick}>{count}</button>;
}

// connectionComponent — rendered inside an <svg> that covers the canvas.
// `type`, `lineStyle`, `width` and `color` arrive already resolved.
function MyArc({ path, color, width, lineStyle }: ConnectionRenderProps<MyData>) {
  const d = path.filter((p) => p.visible).map((p, i) => `${i ? 'L' : 'M'}${p.x},${p.y}`).join(' ');
  return <path d={d} stroke={color} strokeWidth={width} fill="none"
               strokeDasharray={lineStyle === 'dashed' ? '7 5' : undefined} />;
}

// controlsComponent — position it yourself; the container is the positioning context.
function MyControls({ zoomIn, zoomOut, reset, canZoomIn, canReset, camera, messages }: GlobeControlsRenderProps) {
  return (
    <div className="pointer-events-none absolute right-3 top-3">
      <button type="button" className="pointer-events-auto" aria-label={messages.zoomIn} onClick={() => zoomIn()} disabled={!canZoomIn}>+</button>
      <button type="button" className="pointer-events-auto" aria-label={messages.zoomOut} onClick={() => zoomOut()}>-</button>
      <button type="button" className="pointer-events-auto" aria-label={messages.resetView} onClick={reset} disabled={!canReset}>home</button>
      <span>{camera.zoom.toFixed(2)}</span>
    </div>
  );
}
```

The overlay layer is `pointer-events: none` so drags reach the canvas; anything interactive must opt
back in with `pointer-events: auto`.

## Localization

Pass `locale` to translate the built-in UI and the bundled place names. English, Romanian, German,
Spanish, French and Hungarian are built in (`en`, `ro`, `de`, `es`, `fr`, `hu`); a regional tag such
as `de-AT` uses its language.

```tsx
<Globe locale="hu" showCountryNames showCapitals showControls />
```

What changes with the locale:

- the accessible names of the zoom, rotate and reset buttons and of cluster markers (with the
  language's plural rules);
- the hemisphere letters on graticule labels (`30°É` in Hungarian);
- country and capital names in labels, the hover tooltip and the screen-reader announcement;
- the container's `lang` attribute.

Override any string with `messages`. Custom controls and clusters receive the resolved strings as a
`messages` render prop.

```tsx
<Globe locale="de" messages={{ resetView: 'Zurück zur Startansicht' }} />
```

For another language, pass its tag and every string in `messages`. Place names are then read from a
dataset that carries that language: a raw Natural Earth file works through its `NAME_XX` columns, or
supply a `names: { it: '…' }` object per country or capital. Missing names fall back to English.

```tsx
import { Globe, DEFAULT_GLOBE_MESSAGES } from 'react-globe';

<Globe
  locale="it"
  messages={{ ...DEFAULT_GLOBE_MESSAGES.en, zoomIn: 'Ingrandisci', zoomOut: 'Riduci' /* …every string */ }}
/>;
```

`localizedName(place, locale)` returns the same name the globe shows, for your own `onCountryHover` or
`onCountryClick` handlers.

## Assets

Every texture and dataset ships in `dist/assets/` (about 7 MB) and resolves relative to the module
with `new URL('./assets/…', import.meta.url)`. Bundlers that implement that pattern copy the files for
you; the package is tested with Vite. Otherwise copy `node_modules/react-globe/dist/assets` somewhere
you serve and point the `assets` prop at the files:

```tsx
<Globe assets={{ dayTexture: '/my/earth.jpg', countriesGeoJson: myFeatureCollection }} />
```

`assets` replaces the day, normal, specular and cloud textures and the countries and capitals
datasets. Coastlines, borders, elevation and the land-cover raster the shaded styles read are always
the bundled files. `countriesGeoJson` and `capitalsDataset` accept a URL or the parsed data; a raw
Natural Earth countries file works, with `NAME`, `ADMIN`, `ISO_A3` and `ADM0_A3` accepted as fallbacks.

## Performance

- One `requestAnimationFrame` loop, stopped when the canvas leaves the viewport or the tab is hidden.
- The loop draws only when something changed: a globe nobody is interacting with skips
  `renderer.render` and the overlay pass. Cloud drift steps at 10 Hz; overlay sets are recomputed at
  20 Hz; overlay positions are written straight to the DOM, not through React state.
- Unmount disposes every geometry, material and texture, drops every listener, cancels the loop and
  releases the WebGL context. The end-to-end suite mounts and unmounts twenty times and checks that no
  context is leaked.
- Decoded images and parsed datasets are cached per URL for the life of the page, and datasets load
  on demand: a layer that is switched off is never fetched.
- Clustering is a uniform screen-space grid, O(n) in the number of pins.
- The default pin is one instanced mesh: one draw call regardless of count.
- The flat styles' land mesh is triangulated once on an idle callback and shared by every globe on the
  page; outside `cartoon` it is built only once the camera comes closer than 2.4 radii.

## Accessibility

The hovered country is announced through a visually hidden `role="status"` region. The built-in
controls are real buttons with localized `aria-label`s and focus-visible outlines. Every animation the
module runs — flights, auto-rotate, cloud drift, connection flow — stops under
`prefers-reduced-motion`. The globe canvas itself has no keyboard control; use `showControls` or your
own `controlsComponent` for keyboard users.
